About This Page

This repo is basically a little scratchpad for weird C++ projects that were built because they seemed fun at the time. The cards below pull their descriptions from each project README so the page stays honest about what each one actually does.

You’ll find GPU compute demos, CPU renderers, a fluid sim, a black hole toy, file compression, esoteric language runtime stuff, and a vector search index. In other words: random experiments, but compiled.
