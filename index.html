About This Page

This repo is basically a personal web shrine for random C++ experiments, GPU demos, and simulations that were built because they looked fun in the terminal. The cards below borrow their wording from each project README so the page stays honest.

Expect a little bit of everything: fluid sims, black holes, a Monte Carlo ray tracer, π on the GPU, file compression, a Brainfuck interpreter, vector search, and a software rasterizer. It’s basically a late-90s download page for code.
